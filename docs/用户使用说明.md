# 知时 · 用户使用说明

适用版本 1.13.1 · 这份说明随 App 保存，断网也能打开。先记下一件事，再慢慢积累；不必把每一分钟都填满。

保存图片：点击记录或生成图片库中的图片进入预览，长按图片后选「保存图片到相册」，也可直接点底部「保存图片」。Android 10 及以上存入相册「知时」（Pictures/知时），更早版本会让你选择保存位置。保存的是 App 内已存好的图片，不重新生图、不调用模型，也不修改笔记。

生图断网后会显示失败或「提交未确认」，不会自动重新生成。有任务编号时，恢复网络后查询原任务；没有编号时，请先在百炼控制台核对生成和扣费，再点「核对后解除占用」。解除只清理本机状态，不会取消服务端任务或退款；再次生成可能重复扣费。

编辑后点右上角「✓」提交保存，并留在这条记录的阅读模式；点「编辑」可继续修改，点左上角返回才回到列表。阅读时左滑下一页、右滑上一页。页数按实际文字与图片计算，不再把末尾溢出的空白计作一页。

笔记配图：先在「AI 助手侧栏 → 模型配置 → 笔记插画」填写北京地域百炼 API Key，独立于聊天模型 Key。在学习笔记、工作日志、灵感或经验中选中文字，点「配图」。先选择本记录或生成库中的参考图，再点「准备提示词」，也可手动填写。参考图会参与当前助手的视觉理解，不再提前写提示词；更换参考图后需重新准备或手动修改确认。默认 2.1 Turbo、单张、少量必要标签；有参考图时跟随其视觉风格，无参考图时用米白墨绿，可选其他画风。

点「生成图片」后，结果只保存到本机生成库，不自动插入正文。可退出面板或 App；重开后继续查询同一任务，不会自动重新生图。系统结束 App 后不保证持续下载，请重开恢复。需要插入时，回到目标记录放好光标，点「图片 → 生成图片」，预览并选择图片，再点「插入」。生成图可跨记录复用，插入后仍留在图库。选中文字和参考图发送给当前助手（需支持图片），最终提示词与参考图发送给百炼，均可能产生费用，不另弹确认；未选全文、轨迹和 Key 不作为资料发送。文字与技术关系仍需核对，风格不保证完全一致。提交状态不明时先核对百炼控制台，不自动重发。插图可撤销，需点「✓」提交记录；未插入图库不在记录备份中，已插入图片随记录备份。

在正文放好光标，点底部「图片」，选择图片并确认后，会在插入位置显示图片；同一张图片可以重复使用。选图期间若编辑页被系统重建，会恢复对应草稿。插图仍需点右上角「✓」才提交记录，整个插图过程只在本机完成。

插入新图片不会自动增加旧图片与正文之间的空行。原有手动空行保持不变，已经保存的空行也不会批量删除；需要时可自行编辑。

空白记录退出不会保存草稿；输入后清空也不会留下空草稿。仅标题、图片或主动填写的学习信息仍会保留。草稿箱按最近编辑排序，卡片展示类型、保存时间、标题和两行摘要；旧的空壳草稿不再展示，有内容的未命名草稿仍可恢复。编辑和阅读时均可点图片打开大图，双指缩放、双击放大，放大后拖动查看；点「适应屏幕」复位，返回只关闭预览。

## 第一次使用：三分钟开始记录

- 安装 APK 后打开「知时」。已有旧版时直接覆盖安装，不要先卸载；建议升级前导出备份。

- 点底部「记录」→「学习」→「添加学习记录」。填写日期、标题、平台、类型、实际学习分钟和笔记，再保存。手动记录不需要 API Key，也不需要联网。

- 想用 AI，进入「AI 助手」，打开左上角历史侧栏，点底部「模型配置」。默认选择 DeepSeek 模型、填入 API Key 并保存；其他厂商和高级连接设置默认收起，旧配置保留。

> 今天在 B站看了《时间管理》视频，学了 25 分钟。笔记：把长期目标拆成今天的一件事。标签：时间管理。

取不到原标题但你写了笔记时，会生成概括标题，标注非原文标题。保存后可说“刚刚那个视频我学习了15分钟”，确认后只改时长，保留笔记；“又学了15分钟”表示增加。目标不明确时会询问标题或日期。升级不能恢复此前已丢失的笔记，可从原聊天复制后补回。

同一条消息里的“学了15分钟”会记入学习时长，不重复存进笔记；正文中提及的教学时间或引用不会自动删掉。“视频号”等纯平台名不当作内容标题，取不到可靠原标题时按你的笔记生成概括标题。已有记录不会批量重写，需要时可打开详情编辑。

AI 会先给出「待确认的记录」。核对、修改，再点击候选上的保存按钮；聊天完成不等于已经入库。

## 四个底部入口，分别做什么？

- 今日：选择日期，查看当天学习投入、工作净时长和学习目标进度。

- 记录 → 学习：添加、搜索和编辑学习记录，按平台或文章、视频、课程、书籍筛选。

- 记录 → 工作：记上班、休息和下班，查看班次与净工作时间；也可单独保存工作日志和任务进展。

- 记录 → 灵感与经验：保存创意、经验和启发感悟，按发生时间排序，可按类型、标签和日期找回。

- 轨迹：主动开启定位，选择日期查看路线、距离和定位断点。

- AI 助手：整理学习、工作、灵感与经验，核对公开链接、查询历史、回顾主题笔记。

- 模型配置只管理模型连接。备份、目标和说明在「记录」；轨迹导出在「轨迹」；知识页在「AI 助手 → ⋯」，链接搜索沿用现有配置，不再提供配置入口。

## 学习：平台、时长、笔记怎么填？

学习笔记、工作日志、灵感和经验使用统一文档编辑器：正文必填，图片不能代替文字。标题从一行起随内容增高，日期下方直接书写正文。点「标签与信息」修改日期、平台、分钟和标签；学习编辑页不再显示熟练度和判断依据，历史值仍保留。长按选中文字，点底部「加粗」即可直接看到粗体，再点取消；「标题」和「列表」作用于当前或选中的段落，不需输入 Markdown 符号。光标处开启加粗后，新输入文字也会加粗。底部「更多」包含 AI 排版、补全标题与标签、本机草稿和已有记录的删除；手动输入不调用模型，也可全程离线编辑。图片在本机缩放转为 JPEG 并移除 EXIF，不作为图片内容自动发送给 Wiki。

「AI 排版」按文章体裁整理分节、段落和少量重点，生成可视化 Markdown；历史叙事保留时间线，并列事项才使用列表。正文由本机原文片段组装，不摘要、不改写、不补充史实，标题路标也只引用对应原文短语。完整分块处理长文；检测到片段遗漏、重复、乱序或图片／代码变化会拒绝采用。预览后选择采用或保留原文；采用后可撤销。编辑内容仍需点右上角「✓」才提交，返回时改动留作本机草稿。点「阅读」从编辑光标所在页面进入，左滑下一页、右滑上一页，也可点底部翻页按钮；点「编辑」继续修改。多次打开可从「更多 → 本机草稿」找回未提交内容。图片随记录备份，恢复时合并记录与图片；草稿不在记录备份中。

只说「我想记录一条学习记录」「打开工作日志」等会直接打开对应编辑器，不需要模型 Key；包含正文的消息仍由 AI 提取为待确认候选，并自动尝试补全缺失的标题与标签，核对后再保存。补全失败保留正文，可在「调整」中补充；不会编造学习分钟或改写正文。

笔记不设固定字数上限，原文完整保存在手机。Wiki 按片段阅读全部笔记，再分层合并摘要；退出后保存的整理进度可继续，修改来源后重新整理。超长内容仍受手机存储、内存及模型服务限制，分块整理可能增加请求次数和费用。

标题填实际文章、视频或书籍名；没有原标题时可用笔记主题作标题。平台在右上角信息侧栏自由输入。

时长填自己实际学习的分钟数，不是视频总长度或文章预计阅读时间。没有提供时长时 AI 候选可能显示 0 分钟，请在保存前补充；0 不表示没有学习。笔记写自己的理解，标签用于把同一主题的内容归到一起。

点击已保存记录可以查看、编辑或删除。重复记录会提示，请核对日期、标题和平台后处理。

「掌握程度与证据」是选填：可以记录个人自评、独立实践或测验结果。累计阅读时间只是投入，不是自动证明熟练的门槛。

## 工作：上班、休息、下班

工作页默认显示选中日期的日志，不再显示顶部工具栏、重复的工时统计和日期输入栏。「今天／近七天／本月」切换日期浏览方式；周历点日期查看，月历默认折叠，点「查看月历」展开，选好日期后收起。月历保留每日净工时和日志标记，月份箭头可查看历史月份。「工时」页签单独查看班次；日志搜索覆盖全部日期，长列表每页5条。补录日志默认使用选中日期；记录页各分类不再显示顶部工具栏；备份与使用说明在「AI 助手」右上角「⋯」菜单中打开。

工时只记录上下班和休息；工作内容写入「工作日志与任务进展」，一天可以写多份。旧班次备注会自动拆为日志，保留原文与日期，日志不计入工时。AI 同时收到工作时间与内容时分别准备班次和日志，核对后各自保存。

- 开始工作时点「现在上班」。

- 暂停时点「开始休息」，回来点「返回工作」；一天可以记录多次休息。

- 下班点「结束工作」，核对并确认；未结束的休息也会一起结束。

净工作时间 = 班次经过时间 − 休息时间。问「今天工作多久」「今天下班了吗」会直接核对最新本地记录，不调用模型，也不需要 Key；净工时已经扣掉休息，不会再减一次。跨夜区分整班与当天时长，进行中标记截至时间。已记录下班的班次不会重复打卡；要更正请明确提供新的下班日期时间，预览后确认。忘记打点时可以手动添加或编辑班次。跨夜班次要填写真实起止日期，不要把次日下班写到前一天。

> 10 月 7 日 09:00 上班，12:00–13:00 休息，18:00 下班。项目：报告整理。

上述完整班次的净工作时间为 8 小时；AI 生成的候选仍需核对后保存。

只有工作内容、没有上下班时间时，点「记录」→「工作」→「写日志」。工作日志保存日期、原文、标题和标签，不计工时；标题可手填或点击 AI 补全。AI 也能从工作叙述生成待确认日志，不要求补上班时间，不猜时长。

> 今天的工作：完成项目需求梳理，发现两个待核对问题，明天继续确认测试方案。

## 灵感与经验：留住一闪而过的想法

点「记录」→「灵感与经验」，选择「记灵感」或「记经验」。正文必填，标题可手填或点击 AI 补全；可填写标签并调整发生时间，支持补录过去的思考。时间按手机本地时区保存。

灵感与经验保存在手机本地，不计入学习分钟、文章数或工作时长，也不自动作为熟练度证据。点击条目可以阅读、编辑或删除；也可以在 AI 助手里点名讨论。

> 帮我记一条灵感：把读过的文章和项目复盘按主题串起来，形成行动清单。标签：知识管理。

> 帮我记一条经验：2026 年 10 月 12 日 15:20，沟通需求前先确认对方的目标，比直接给方案更有效。标签：沟通。

> 找出我上个月6号的灵感和经验，并引用原始记录。

> 回顾我关于知识管理的学习、灵感和经验，建立主题 Wiki；区分设想和已经实践的体会。

聊天提取先生成候选，核对类型、内容和发生时间再确认保存。说「现在」或没有提供时间的即时记录会按当前手机时间准备；只给过去日期却没有时刻时，AI 应先询问，不编造时间。

历史检索会按日期、类型或主题选择相关原始记录；Wiki 是模型整理，新增、修改或删除来源后会标记待更新。整理会发送相关学习、灵感和经验内容给所选模型并产生请求费用；不是自动上传全部记录。知识页仅供回顾，不把个人经验或未验证创意当成普遍事实。

## API Key 填在哪里？

- 进入「AI 助手」，在左上角历史侧栏底部打开「模型配置」；选择 DeepSeek、GLM 或自定义兼容接口。

- 核对模型名称，填入自己的 API Key。一般厂商的地址和协议已预设；需要修改时展开「高级连接设置」。地址只填基础地址，保留服务商所需路径，不加 /chat/completions 或 /responses。

- 在「API Key」密码框粘贴自己的密钥，再点「保存模型配置」。显示／隐藏仅针对正在输入的密钥；已保存的密钥不会回显。不要把密钥发到聊天或公开截图里。

输入框留空保存会保留原密钥；要更换密钥，直接填写新的Key并保存。已移除删除密钥及允许内网的勾选项。公网必须使用HTTPS；HTTP仅支持本机或私有内网IP，明文传输请谨慎。切换厂商会暂存未保存的输入，重新打开App后未保存输入会丢弃；保存后清除密钥草稿。推理强度、工具调用和图片输入须得到实际模型支持，配置保存成功不等于连接已测试。

模型 Key 由你向对应服务商获取，AI 请求按其规则计费。DeepSeek 搜索／抓取复用官方模型 Key 并单独按次计费；非官方代理 Key 不能直接使用官方工具。Exa 免搜索 Key 不代表聊天免费。HTTP 仅适用于你信任的内网；它不是加密传输，公网优先使用 HTTPS。

## AI：链接、图片、文件与历史问答

发文字可同时给出标题、日期、分钟和笔记；发公开链接时先确认是否允许联网。读取成功后仍要检查原文标题与类型。网页内容是参考资料，不自动当成你的个人学习笔记。

图片或文件从输入框旁「＋」选择。图片需要视觉模型；支持文本、可提取文字的 PDF 和 DOCX。不支持直接理解视频内容或自动读完整本书。扫描 PDF 没有文字时，可改发相关页面截图并使用视觉模型。大文件请拆成相关章节。

> 2026 年 10 月 6 日我学了什么？学习多久，净工作多久？

> 总结我关于 JEV 模型应用的学习笔记，建立主题 Wiki，并引用原始记录。

> 从已记录的实践和测验里，看看我的进步与投入有什么关联。数据不足请直说。

日期和时长从本地记录计算，主题 Wiki 由所选模型整理，会增加 API 请求。原始笔记变化后可以更新 Wiki。没有记录不等于那天投入为 0；AI 无法知道没有记录的生活，也不能把「学了 50 小时」当成人人适用的熟练标准。

聊天页采用简洁顶栏、居中问候和圆角底部输入框。左上角打开侧边历史，可搜索标题与对话正文，按今天、昨天、7 天内等分组；右上角新建对话，「⋯」查看知识库或清空当前会话。模型配置收在历史侧栏底部。滚动查看旧内容时点向下箭头回到底部；键盘弹出时隐藏底部导航，收起后恢复。输入框支持多行，回复期间可继续写草稿。

同一会话保留多轮上下文，不再只取最后几条；长会话采用类似 Pi 的压缩方式，保存旧轮次的目标、事实、决定和待办，保留最近完整轮次。摘要可能有遗漏，重要信息可查看原始历史并纠正。压缩额外调用模型并可能计费；原始聊天不会被压缩删除，各会话的聊天记忆不会混用。生活数据库与 Wiki 仍是共享知识库。

## AI 修改记录：先预览，再确认

可以让 AI 更正学习时长、标题、平台、日期、标签或内容，追加工作进展，修改灵感与经验，或准备上班、休息、返回工作、下班操作。修改已有内容时请提供日期、标题或记录编号；目标不明确时先核对。打卡可直接说「我上班了」「开始休息」「休息结束了」「我下班了」，休息／下班自动关联唯一进行中班次；也可说「今天09:00上班」「今天13:00结束休息」。补录请给明确日期与24小时制时间。未点击确认前不会写入，重复上班、未来时间或顺序错误会提示。

> 把10月12日《时间管理》的学习时长改为40分钟，其他内容不变。

> 追加10月12日的工作日志：测试已通过，下一步核对交付清单，保留原内容。

上下班和休息打卡只显示动作、日期、时间与确认／取消；跨日班次和下班同时结束休息会额外提示。普通记录修改可展开字段查看修改前后，再点「确认更新」。删除需再次确认。准备候选不等于执行；如果记录在等待确认时被其他编辑修改，App 会拒绝旧变更，重新检索后再确认，不覆盖新内容。

目前开放的是生活记录操作，不是让模型任意控制手机。定位、地图、密钥、备份和权限仍由你操作；掌握程度与证据可在学习编辑器手动调整。AI 不能读取未记录的生活或自行开启定位。

## 自动 Wiki：默认整理，无需配置

模型配置可用后，Wiki默认自动整理，无需开关或额度配置。没有App每日次数限制，按队列逐批整理；服务商限流、余额与收费仍然适用，可能持续产生API费用，相关内容会发送给当前模型服务商。

保存、编辑、删除或导入学习、工作内容、工作日志、灵感与经验会在本地排队。App在前台空闲时自动归类并整理相关主题；优先采用标签，没有标签时由模型提取主题。整理结果保留原始来源，不覆盖你的原文，不把创意当作已验证事实。

关闭App后暂停，下次打开继续，不是全天后台服务。失败保留队列并自动退避重试，最多间隔15分钟；网络、余额或Key恢复后自动继续，不再需要手动重试。历史问答仍检索原始记录，过期摘要不作为最新知识。

升级保留待整理队列，首次打开此版本会把已有学习、工作内容、灵感与经验自动加入内部队列，无需点击整理按钮。模型配置有效后逐批发送相关内容给当前服务商，可能持续计费。长笔记逐块阅读全部原文，分层合并成主题摘要；整理进度保存在手机，尚未完成时继续排队，不以截断摘要冒充完整整理；不发送轨迹或模型Key作为知识内容。

## 知识发现：联系、冲突与缺口

入口：AI 助手右上角「⋯」→「本地 LLM Wiki」，顶部查看跨领域联系、观点冲突和知识缺口。不增加底部模块，使用当前模型配置，无需另外设置。

保存或修改笔记后，先自动更新主题知识页，再逐批检查单个主题以及不同主题对。已分析且来源没变化的范围不会反复请求；新增、修改或删除相关来源后重新分析。主题越多，比较任务越多，可能持续产生 API 费用；仅在 App 前台空闲时运行，关闭后暂停，下次继续。

跨领域联系：例如学习中的「数据治理」与工作中的「返工复盘」，AI 可以提出「输入质量影响结果质量」这个共同机制，并列出两边笔记、原文引句和迁移的限制。这只是可验证的线索，不代表两个领域已经被证明遵循同一规律。

观点冲突：例如一条笔记写「先设计指标」，另一条写「先上线再补指标」。App 保留双方主张及来源日期，请你核对是不是业务阶段不同、适用条件不同或观点随时间变化，不自动删除旧观点、不裁定谁正确。

知识缺口：例如记录了很多 REA 阅读心得，但当前笔记没有独立实践结果。AI 只能提示「现有记录缺少实践验证证据」，不能因此说你不会。你可以按建议补充实践笔记，之后自动重新分析；补一条记录不等于自动证明缺口已解决。

点击发现可查看依据、需要核实的问题、可选下一步和原始来源。可标记待跟进、暂不采纳、已处理，标记已处理必须填写自己的核对说明；这些状态不改写笔记。暂不采纳默认不进入聊天上下文，可在历史查看。

来源变化时，旧发现标为待复核，不再用于问答，也不能继续标为已核对。重新分析后保留旧版本及处理说明供查看；新证据不会自动沿用旧的已处理结论或暂不采纳状态。旧结果不再出现，也不代表它已经被证明错误或缺口已解决。

可以直接问「我有哪些观点冲突？」「关于数据治理的知识缺口有哪些？」「有哪些跨领域联系值得验证？」。回答只使用当前有效发现及其真实来源，不附无关工时统计；尚未完成分析或没有结果时，不代表不存在联系、冲突或缺口。

主题整理仍分块读取全部笔记；知识发现则利用主题摘要，并从每个主题抽取首、中、末代表记录的原文片段核对，不是全文穷举，不保证发现所有问题。引句由 App 再次逐字核验，但模型对联系和冲突的解释仍可能有误，需要个人核实。

以上数据治理、指标和 REA 均为功能示例，不代表你的真实记录或实际能力判断。

## 链接读不到，或 AI 请求失败怎么办？


先检查链接有没有拼接说明文字，最好让网址单独占一行。公众号验证码、登录、付费页和网络限制可能导致读取失败；不会自动登录或绕过这些限制。

当前模型使用 DeepSeek 官方地址及 Key 时，公开链接先直接读取，不足时使用 DeepSeek Fetch 抓取，再按需 Search 核对同一链接。每次有效请求约 0.005 元。发送公开链接后直接按需调用，不再弹出读取或费用确认；调用仍按服务商规则计费。只发送公开 URL，不发送本地历史、定位或附件正文；官方 Key 仅用于 DeepSeek 鉴权，不发送给文章网站。其他厂商沿用原搜索服务，已关闭的偏好保留；不自动跨服务兜底。验证、登录、付费墙或站点限制仍可能导致失败，可粘贴正文或发截图。

仍读不到时：手动补原标题，或复制你有权阅读的相关正文，或发标题和内容截图。搜到主题相似的页面不代表找到了原文；保存前请检查来源链接。

AI 连接失败时依次检查网络、API 地址、模型名称、协议、Key 是否有效和额度。图片失败时检查视觉支持。不要把真实 Key 附在故障截图里。

## 全天轨迹与地图：怎么看才准确？

选择日期后，在地图上方切换「全天／时间段／时刻」。「时间段」可快速选 09:00—10:00 等整点一小时，也可自选开始和结束；只显示开始时刻起、结束时刻前的轨迹，结束 00:00 表示次日零点。「时刻」输入 09:30 后定位：显示前后60秒内最近的可用处理点、实际记录时间与时间差，不插值伪造精确位置；无记录时可点此前／此后记录查看相邻位置。停留估计和定位误差仍可能存在。换日期恢复全天；查询只在本机运行，不改全天距离、原始点或GPX。

在「轨迹」点「开启 / 继续记录」，同意精确定位和通知。锁屏后持续定位会耗电；小米的后台定位、自启动和省电策略需在手机系统设置中自行调整。暂停后停止采集，重新开启才继续。

金色（D）或绿色（运动辅助）的实线是已记录并处理后的点间连线。紫色虚线表示推断，不计里程：有可信离线路网匹配时沿道路绘制，其余相邻轨迹段按时间直接补连。没有数据的路线仍是未知的；室内、高楼旁或后台受限时，不能保证导航级精度。

<strong>离线道路推断：</strong>轨迹页点「导入路网」，选择本地区域的 OpenStreetMap XML（.osm，最大128MB）。这是独立于地图底图的道路数据，Mapsforge .map、MBTiles、PBF不能代替。路网只存手机，不需要Key，也不会上传轨迹；导入后自动匹配有移动证据的历史路线。关闭「离线道路推断」可看原处理轨迹。「轨迹数据」中可选择步行、骑行、乘车或自动。

路网匹配综合整段位置、时间、可达性和出行方式，不是吸附最近道路。静止、长缺口、平行路难以区分或路网缺失时不强制匹配。原始点、参考距离、普通GPX均不改变；推断结果不进入AI上下文。路网不包含所有室内通道，不提供建筑入口识别、完整交通转向限制或导航。软件不内置城市路网；如有本地区域OSM XML可直接导入，也可在电脑上从OpenStreetMap导出较小区域的OSM XML后传到手机。

### 离线道路推断（1.9.7）

轨迹页 →「导入路网」→ 选择本地区域的 OpenStreetMap XML（`.osm`，最大128MB）。无需API Key，无轨迹上传；路网导入后自动在本机处理有移动证据的历史路线。关闭「离线道路推断」可查看原处理轨迹。轨迹数据面板可以选择步行、骑行、乘车或自动（依据可信GPS速度；证据不足按步行保守尝试）。

底图与路网是两份不同的数据。`.map`、MBTiles只是现有地图入口，不能代替这里的OSM XML；暂不支持PBF或压缩路网。软件不内置城市路网，也不自动联网下载。可以在电脑的 [OpenStreetMap](https://www.openstreetmap.org/export) 选择较小区域，导出OSM XML后传到手机；请勿向第三方上传私人轨迹来获取路网。大区域应离线裁剪后再导入。

这是整段序列匹配，不是逐点吸附最近道路：使用真实OSM节点连接、出行通行属性、时间与距离约束。静止、长缺采、缺图、并行道路难区分时保留原轨迹。已知道路节点缺失不会被直连成新道路。道路推断只改变地图，不改原始库、现有参考距离或普通GPX。数据缺失不能靠规划路线还原。

本版不支持室内定位、建筑入口识别、完整交通转向限制或导航；道路匹配不等于真实走过的人行道。推断结果可重算，不覆盖采样，也不注入AI上下文。当前需要「停留与移动识别」提供移动证据；旧D方案仍保持原样。

选择日期，拖动地图，用「＋」「−」缩放、「全程」回到整条路线；点路线可看时间与定位误差，展开断点可查看对应时间。

默认离线 OSM。可导入有权使用的 Mapsforge .map 矢量地图（推荐）或标准栅格 TMS MBTiles，最大512MB；不支持OSM PBF或矢量MBTiles。App不内置城市地图包，也不自动下载。Mapsforge按当前级别本机渲染到18级，放大更清晰，但不能增加地图包原本没有的街道。栅格缺级仍按地理范围裁剪低级别底图并提示「低清放大」；区域无地图时显示网格。在线OSM需同意联网，对方会收到区域请求及IP；离线不下载图块。

在线／离线可以反复切换。切换期间选择框会短暂禁用，完成后恢复；取消联网确认时保留原模式。地图慢请求与切换操作分开，并取消旧视图请求，避免旧图块或旧状态覆盖新选择。在线单个图块失败不会停止其他区域的加载；网络恢复后可点「刷新轨迹」重试。

「轨迹」→「轨迹数据 · 导出与管理」可导出当前方案的完整GPX、未经筛选的原始GPX或定位诊断。均含精确位置和时间，只分享给信任的人；原始GPX可能含漂移、重复及过旧回调，不代表可靠行程。轨迹不发送给AI或外部匹配服务；没有GPX恢复入口。删除当天轨迹不可撤销，先导出；采集中仍可能产生新点。

## 轨迹处理与全部定位反馈

在「轨迹 → 轨迹数据」点击「导出全部定位反馈包」，确认后选择保存位置，即可一次导出所有已保存日期的原始定位、速度、误差与已有运动传感器诊断，包括未纳入轨迹的点。反馈包为一个 ZIP，内含逐行原始数据、日期清单、版本和完整性校验，不受单日导出点数限制；不含模型 Key、学习笔记或离线底图。数据较多时请保持 App 打开，待显示保存完成再分享。它含完整行踪，仅保存到你选择的位置，不会自动上传或发给 AI。

打开「轨迹」并选择日期，默认使用「停留与移动识别」；「轨迹处理」可切换到旧版D对照，对照同一天的点数、距离和路线。选择保存在本机，不改变原始记录。

旧版 D 方案只显示已保存且误差估计不超过65米的有效GPS点，卫星数0等信号信息不再单独否决位置；先做轻量异常跳点筛选，再对相邻三点按误差加权，明显拐弯不平滑。65米是筛选上限，不是保证实际误差在65米内。

地图、参考距离、诊断的处理结果和普通GPX采用所选同一方案；原始GPX不做筛选。处理后GPX不包含紫色虚线，过去导出的文件不变。升级后默认启用改进的停留与移动识别，已有轨迹按原始点重新计算，不改写原始库。新策略以自适应多点时间窗判断停留、移动和不确定状态，兼容较稀疏的旧采样；有近期运动证据和连续位移时，短时间局部转弯或绕行也可保留。单帧移动判断仍只作待确认参考，拿起手机本身不等于产生行程。停留估计锁住代表位置，持续位移或可信速度支持后才画移动轨迹；运动传感器缺失时使用更保守的位置趋势判断，不等同于静止。无法确认的点不再直接丢弃，以虚线参考保留；连续待确认时段合并展示，但保留中间位置和时间顺序。有停留依据时，缺少离开证据的远端漂移会沿用停留锚点，并标为位置待确认，不代表已测得当前位置。可能漏掉弱信号下的短途移动。优先使用手机可用的唤醒型运动传感器，线性加速度不可用时退化为去重力加速度；不使用常驻唤醒锁；非唤醒传感器数据过旧时，随定位回调最多每30秒唤醒CPU 2.5秒补采，可能略增耗电，仍不能保证小米息屏后持续返回数据。匀速车辆不会仅因加速度低而判停，不积分生成坐标，不是完整惯性导航。Android12及以上可用时记录系统fused备援，新策略仅在GPS缺失15秒且误差不超35米时采用，并保留来源、在来源变化时分段。D仍只使用GPS。两种距离均是参考估计，不是实测校准值。

采集请求从约5秒调整为约2秒，实际频率由系统决定，耗电可能增加；持续缺失时最多每2分钟尝试重订阅，不能绕过小米省电限制。合法坐标及误差估计1000米以内的回调先存原始库，不再入库前丢弃4秒内或跳移点，过旧和重复回调标记后不纳入轨迹。支持全天43200个点；绘图必要时按1米容差、15秒窗口简化，距离和普通GPX仍使用完整处理点。没有保存过的旧位置无法找回。

## 截图与隐私

App 允许系统截图，不自动截屏、录屏或上传屏幕。小米通常可用「电源键＋音量减」短按或系统截图手势；具体方式以机型设置为准。长截图由系统决定，不保证每个弹窗都支持。

分享前检查文章笔记、工作内容、位置、坐标和正在输入的 Key，裁剪或打码敏感部分。密钥字段保持密码显示；允许截图也意味着系统最近任务预览可能显示当前内容。

如系统提示不能截图，先确认是否处于知时页面，再检查工作资料或设备管理策略；App 不会绕过系统管控。

记录原文保存在本机；配置可用模型后，相关记录默认自动发送给所选服务商整理Wiki，可能计费。聊天输入与相关检索笔记也会发送给模型。公开链接读取或搜索需同意联网。密钥加密保存，但记录库和导出备份没有额外加密，注意妥善保管。

建议每天用两分钟回顾：今天学了什么、投入多久、能做什么新事情？记录用来帮助反馈与调整，不用来惩罚自己。
