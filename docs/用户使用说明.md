# 知时 · 用户使用说明

适用版本 1.7.6 · 这份说明随 App 保存，断网也能打开。先记下一件事，再慢慢积累；不必把每一分钟都填满。

## 第一次使用：三分钟开始记录

- 安装 APK 后打开「知时」。已有旧版时直接覆盖安装，不要先卸载；建议升级前导出备份。

- 点底部「记录」→「学习」→「添加学习记录」。填写日期、标题、平台、类型、实际学习分钟和笔记，再保存。手动记录不需要 API Key，也不需要联网。

- 想用 AI，进入「AI 助手」，打开左上角历史侧栏，点底部「模型配置」。选择厂商、核对模型名称、填入 API Key 并保存；协议、地址、推理强度在「高级连接设置」，图片输入默认支持。

> 今天在 B站看了《时间管理》视频，学了 25 分钟。笔记：把长期目标拆成今天的一件事。标签：时间管理。

AI 会先给出「待确认的记录」。核对、修改，再点击候选上的保存按钮；聊天完成不等于已经入库。

## 四个底部入口，分别做什么？

- 今日：选择日期，查看当天学习投入、工作净时长和学习目标进度。

- 记录 → 学习：添加、搜索和编辑学习记录，按平台或文章、视频、课程、书籍筛选。

- 记录 → 工作：记上班、休息和下班，查看班次与净工作时间；也可单独保存工作日志和任务进展。

- 记录 → 灵感与经验：保存创意、经验和启发感悟，按发生时间排序，可按类型、标签和日期找回。

- 轨迹：主动开启定位，选择日期查看路线、距离和定位断点。

- AI 助手：整理学习、工作、灵感与经验，核对公开链接、查询历史、回顾主题笔记。

- 模型配置只管理模型连接。备份、目标和说明在「记录」；轨迹导出在「轨迹」；知识页在「AI 助手 → ⋯」，链接搜索沿用现有配置，不再提供配置入口。

## 学习：平台、时长、笔记怎么填？

笔记不设固定字数上限，原文完整保存在手机。Wiki 按片段阅读全部笔记，再分层合并摘要；退出后保存的整理进度可继续，修改来源后重新整理。超长内容仍受手机存储、内存及模型服务限制，分块整理可能增加请求次数和费用。

标题填实际文章、视频或书籍名；平台可自由输入。常用平台按钮可展开或收起，不必从列表中选择。

时长填自己实际学习的分钟数，不是视频总长度或文章预计阅读时间。没有提供时长时 AI 候选可能显示 0 分钟，请在保存前补充；0 不表示没有学习。笔记写自己的理解，标签用于把同一主题的内容归到一起。

点击已保存记录可以查看、编辑或删除。重复记录会提示，请核对日期、标题和平台后处理。

「掌握程度与证据」是选填：可以记录个人自评、独立实践或测验结果。累计阅读时间只是投入，不是自动证明熟练的门槛。

## 工作：上班、休息、下班

工作页默认显示选中日期的日志，月历默认折叠，点「查看月历」展开，选好日期后收起；「今天／近七天／本月」切换汇总范围，日历显示每日净工时和日志标记，点击日期查看当天内容。「工时」页签单独查看班次；日志搜索覆盖全部日期，长列表每页5条。月份箭头可查看历史月份，补录日志默认使用选中日期。

工时只记录上下班和休息；工作内容写入「工作日志与任务进展」，一天可以写多份。旧班次备注会自动拆为日志，保留原文与日期，日志不计入工时。AI 同时收到工作时间与内容时分别准备班次和日志，核对后各自保存。

- 开始工作时点「现在上班」。

- 暂停时点「开始休息」，回来点「返回工作」；一天可以记录多次休息。

- 下班点「结束工作」，核对并确认；未结束的休息也会一起结束。

净工作时间 = 班次经过时间 − 休息时间。问「今天工作多久」「今天下班了吗」会直接核对最新本地记录，不调用模型，也不需要 Key；净工时已经扣掉休息，不会再减一次。跨夜区分整班与当天时长，进行中标记截至时间。已记录下班的班次不会重复打卡；要更正请明确提供新的下班日期时间，预览后确认。忘记打点时可以手动添加或编辑班次。跨夜班次要填写真实起止日期，不要把次日下班写到前一天。

> 10 月 7 日 09:00 上班，12:00–13:00 休息，18:00 下班。项目：报告整理。

上述完整班次的净工作时间为 8 小时；AI 生成的候选仍需核对后保存。

只有工作内容、没有上下班时间时，点「记录」→「工作」→「写日志」。工作日志保存日期、原文、标题和标签，不计工时；标题可留空。AI 也能从工作叙述生成待确认日志，不要求补上班时间，不猜时长。

> 今天的工作：完成项目需求梳理，发现两个待核对问题，明天继续确认测试方案。

## 灵感与经验：留住一闪而过的想法

点「记录」→「灵感与经验」，选择「记灵感」或「记经验」。内容必填，标题可留空，保存时从内容首句提取；可填写标签并调整发生时间，支持补录过去的思考。时间按手机本地时区保存。

灵感与经验保存在手机本地，不计入学习分钟、文章数或工作时长，也不自动作为熟练度证据。点击条目可以编辑、删除，或用「交给 AI 回顾 / 讨论」预填聊天框；只有点击发送后才交给所选模型。

> 帮我记一条灵感：把读过的文章和项目复盘按主题串起来，形成行动清单。标签：知识管理。

> 帮我记一条经验：2026 年 10 月 12 日 15:20，沟通需求前先确认对方的目标，比直接给方案更有效。标签：沟通。

> 找出我上个月6号的灵感和经验，并引用原始记录。

> 回顾我关于知识管理的学习、灵感和经验，建立主题 Wiki；区分设想和已经实践的体会。

聊天提取先生成候选，核对类型、内容和发生时间再确认保存。说「现在」或没有提供时间的即时记录会按当前手机时间准备；只给过去日期却没有时刻时，AI 应先询问，不编造时间。

历史检索会按日期、类型或主题选择相关原始记录；Wiki 是模型整理，新增、修改或删除来源后会标记待更新。整理会发送相关学习、灵感和经验内容给所选模型并产生请求费用；不是自动上传全部记录。知识页仅供回顾，不把个人经验或未验证创意当成普遍事实。

## API Key 填在哪里？

- 进入「AI 助手」，在左上角历史侧栏底部打开「模型配置」；选择 DeepSeek、GLM 或自定义兼容接口。

- 核对模型名称，填入自己的 API Key。一般厂商的地址和协议已预设；需要修改时展开「高级连接设置」。地址只填基础地址，保留服务商所需路径，不加 /chat/completions 或 /responses。

- 在「API Key」密码框粘贴自己的密钥，再点「保存模型配置」。显示／隐藏仅针对正在输入的密钥；已保存的密钥不会回显。不要把密钥发到聊天或公开截图里。

输入框留空保存会保留原密钥；要更换密钥，直接填写新的Key并保存。已移除删除密钥及允许内网的勾选项。公网必须使用HTTPS；HTTP仅支持本机或私有内网IP，明文传输请谨慎。切换厂商会暂存未保存的输入，重新打开App后未保存输入会丢弃；保存后清除密钥草稿。推理强度、工具调用和图片输入须得到实际模型支持，配置保存成功不等于连接已测试。

模型 Key 由你向对应服务商获取，AI 请求按其规则计费。Exa 搜索免搜索 Key，不代表 AI 聊天免模型 Key。HTTP 仅适用于你信任的内网；它不是加密传输，公网优先使用 HTTPS。

## AI：链接、图片、文件与历史问答

发文字可同时给出标题、日期、分钟和笔记；发公开链接时先确认是否允许联网。读取成功后仍要检查原文标题与类型。网页内容是参考资料，不自动当成你的个人学习笔记。

图片或文件从输入框旁「＋」选择。图片需要视觉模型；支持文本、可提取文字的 PDF 和 DOCX。不支持直接理解视频内容或自动读完整本书。扫描 PDF 没有文字时，可改发相关页面截图并使用视觉模型。大文件请拆成相关章节。

> 2026 年 10 月 6 日我学了什么？学习多久，净工作多久？

> 总结我关于 JEV 模型应用的学习笔记，建立主题 Wiki，并引用原始记录。

> 从已记录的实践和测验里，看看我的进步与投入有什么关联。数据不足请直说。

日期和时长从本地记录计算，主题 Wiki 由所选模型整理，会增加 API 请求。原始笔记变化后可以更新 Wiki。没有记录不等于那天投入为 0；AI 无法知道没有记录的生活，也不能把「学了 50 小时」当成人人适用的熟练标准。

聊天页采用简洁顶栏、居中问候和圆角底部输入框。左上角打开侧边历史，可搜索标题与对话正文，按今天、昨天、7 天内等分组；右上角新建对话，「⋯」查看知识库或清空当前会话。模型配置收在历史侧栏底部。滚动查看旧内容时点向下箭头回到底部；键盘弹出时隐藏底部导航，收起后恢复。输入框支持多行，回复期间可继续写草稿。

同一会话保留多轮上下文，不再只取最后几条；长会话采用类似 Pi 的压缩方式，保存旧轮次的目标、事实、决定和待办，保留最近完整轮次。摘要可能有遗漏，重要信息可查看原始历史并纠正。压缩额外调用模型并可能计费；原始聊天不会被压缩删除，各会话的聊天记忆不会混用。生活数据库与 Wiki 仍是共享知识库。

## AI 修改记录：先预览，再确认

可以让 AI 更正学习时长、标题、平台、日期、标签或内容，追加工作进展，修改灵感与经验，或准备上班、休息、返回工作、下班操作。修改已有内容时请提供日期、标题或记录编号；目标不明确时先核对。打卡可直接说「我上班了」「开始休息」「休息结束了」「我下班了」，休息／下班自动关联唯一进行中班次；也可说「今天09:00上班」「今天13:00结束休息」。补录请给明确日期与24小时制时间。未点击确认前不会写入，重复上班、未来时间或顺序错误会提示。

> 把10月12日《时间管理》的学习时长改为40分钟，其他内容不变。

> 追加10月12日的工作日志：测试已通过，下一步核对交付清单，保留原内容。

AI 返回「待确认的变更」，展开字段查看修改前后，再点「确认更新」。删除需再次确认。准备候选不等于执行；如果记录在等待确认时被其他编辑修改，App 会拒绝旧变更，重新检索后再确认，不覆盖新内容。

目前开放的是生活记录操作，不是让模型任意控制手机。定位、地图、密钥、备份和权限仍由你操作；掌握程度与证据可在学习编辑器手动调整。AI 不能读取未记录的生活或自行开启定位。

## 自动 Wiki：默认整理，无需配置

模型配置可用后，Wiki默认自动整理，无需开关或额度配置。没有App每日次数限制，按队列逐批整理；服务商限流、余额与收费仍然适用，可能持续产生API费用，相关内容会发送给当前模型服务商。

保存、编辑、删除或导入学习、工作内容、工作日志、灵感与经验会在本地排队。App在前台空闲时自动归类并整理相关主题；优先采用标签，没有标签时由模型提取主题。整理结果保留原始来源，不覆盖你的原文，不把创意当作已验证事实。

关闭App后暂停，下次打开继续，不是全天后台服务。失败保留队列并自动退避重试，最多间隔15分钟；网络、余额或Key恢复后自动继续，不再需要手动重试。历史问答仍检索原始记录，过期摘要不作为最新知识。

升级保留待整理队列，首次打开此版本会把已有学习、工作内容、灵感与经验自动加入内部队列，无需点击整理按钮。模型配置有效后逐批发送相关内容给当前服务商，可能持续计费。长笔记逐块阅读全部原文，分层合并成主题摘要；整理进度保存在手机，尚未完成时继续排队，不以截断摘要冒充完整整理；不发送轨迹或模型Key作为知识内容。

## 链接读不到，或 AI 请求失败怎么办？


先检查链接有没有拼接说明文字，最好让网址单独占一行。公众号验证码、登录、付费页和网络限制可能导致读取失败；不会自动登录或绕过这些限制。

链接识别与搜索直接沿用已保存的服务与开关，未配置时默认 Exa 匿名 MCP，无需搜索Key；不再提供搜索配置按钮。发送公开链接即可使用，仍会提示是否允许访问。服务可能限流或不可用；不会自动切换到收费服务。

仍读不到时：手动补原标题，或复制你有权阅读的相关正文，或发标题和内容截图。搜到主题相似的页面不代表找到了原文；保存前请检查来源链接。

AI 连接失败时依次检查网络、API 地址、模型名称、协议、Key 是否有效和额度。图片失败时检查视觉支持。不要把真实 Key 附在故障截图里。

## 全天轨迹与地图：怎么看才准确？

在「轨迹」点「开启 / 继续记录」，同意精确定位和通知。锁屏后持续定位会耗电；小米的后台定位、自启动和省电策略需在手机系统设置中自行调整。暂停后停止采集，重新开启才继续。

金色实线是已记录并加权平滑后的点间连线；相邻轨迹段的终点与起点始终按时间用紫色虚线直接连接，包括长缺口、定位过滤和暂停期间。虚线不计里程，不按空间最近匹配，也不代表真实走过的道路；没有数据的路线仍是未知的。室内、高楼旁、弱信号或后台被限制时仍可能漂移或缺失，不能保证导航级精度。

选择日期，拖动地图，用「＋」「−」缩放、「全程」回到整条路线；点路线可看时间与定位误差，展开断点可查看对应时间。

默认离线 OSM。App 不内置城市街道地图包，可导入自己准备的标准栅格 TMS MBTiles。放大时优先用当前级别的图块，缺少时按地理范围裁剪已有的低级别底图，并提示「低清放大」；这不会增加街道细节或提升定位精度。完全没有覆盖此区域的图块时仍显示网格。在线 OSM 需要联网同意，对方会收到图块区域请求及 IP；离线模式不会下载缺少的图块。

在线／离线可以反复切换。切换期间选择框会短暂禁用，完成后恢复；取消联网确认时保留原模式。地图慢请求与切换操作分开，并取消旧视图请求，避免旧图块或旧状态覆盖新选择。在线单个图块失败不会停止其他区域的加载；网络恢复后可点「刷新轨迹」重试。

「轨迹」→「轨迹数据 · 导出与管理」可选择日期导出 GPX 或定位诊断。二者含精确位置和时间，请只分享给信任的人。轨迹不发送给 AI；目前没有 GPX 恢复入口。删除当天轨迹不可撤销，先导出；采集中仍可能产生新点。

## 轨迹处理：65米＋误差加权平滑

打开「轨迹」并选择日期，App自动使用65米＋误差加权平滑（原D方案），没有其他方案或切换入口；旧版保存的常用方案不再影响显示。

只显示已保存且误差估计不超过65米的有效GPS点，卫星数0等信号信息不再单独否决位置；先做轻量异常跳点筛选，再对相邻三点按误差加权，明显拐弯不平滑。65米是筛选上限，不是保证实际误差在65米内。

地图、轨迹参考距离、定位诊断的过滤结果和新导出的GPX均使用同一算法。GPX仅保存各段有效轨迹，不包含紫色虚线；过去导出的文件不会自动改变。参考距离可能受漂移影响，不是实际路程校准值。

计算仅在本机，不发送AI、不请求道路吸附或导航。平滑改变的是展示及导出副本，不覆盖数据库原始坐标，也不增加缺失时间的采样。全天采集规则不变，没有保存过的定位无法找回。

## 备份、升级与换手机

- 「记录」→「记录与备份」→「导出备份」，在系统文件选择器中选保存位置。

- 将备份文件另存到你信任的设备或存储位置，建议每周一次、升级前一次。

- 在「记录」→「记录与备份」点「恢复记录」并选择备份，确认后合并原始学习、工作班次、工作日志、灵感与经验记录，重复条目跳过。

生活备份包含记录、对话和 Wiki，但恢复只合并原始记录，不恢复对话、Wiki 缓存或模型配置；Wiki 可重新整理。备份不含任何 Key、定位轨迹或离线地图。

换手机后重新填写模型 Key；轨迹请另行导出留存。不要在未备份前卸载或清除数据。同签名 APK 可覆盖升级保留数据，自己从源码生成的新签名不能直接覆盖旧版。

## 截图与隐私

App 允许系统截图，不自动截屏、录屏或上传屏幕。小米通常可用「电源键＋音量减」短按或系统截图手势；具体方式以机型设置为准。长截图由系统决定，不保证每个弹窗都支持。

分享前检查文章笔记、工作内容、位置、坐标和正在输入的 Key，裁剪或打码敏感部分。密钥字段保持密码显示；允许截图也意味着系统最近任务预览可能显示当前内容。

如系统提示不能截图，先确认是否处于知时页面，再检查工作资料或设备管理策略；App 不会绕过系统管控。

记录原文保存在本机；配置可用模型后，相关记录默认自动发送给所选服务商整理Wiki，可能计费。聊天输入与相关检索笔记也会发送给模型。公开链接读取或搜索需同意联网。密钥加密保存，但记录库和导出备份没有额外加密，注意妥善保管。
