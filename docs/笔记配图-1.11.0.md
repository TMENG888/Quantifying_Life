# 笔记配图 · 1.11.0

## 使用

1. AI 助手 → 左上角历史侧栏 → 模型配置 → 笔记插画：填写北京地域百炼生图 Key 并保存。已有聊天模型继续用于准备提示词，两套配置互不覆盖。
2. 打开学习、工作日志、灵感或经验的编辑页，长按选中一段文字，点底栏「配图」。
3. 等待当前助手生成提示词，也可直接手动输入。选择模型、系列画风、画幅、清晰度和 1–2 张。默认 2.1 Turbo、米白墨绿、横图、单张、无文字。
4. 可选本记录中的图片作风格参考。点击「生成并插入段落下方」后直接提交百炼，不再询问费用。
5. 图片下载到本机后插入所选段落下方，保留正文及旧图片；支持撤销／重做、点击大图。点右上角 ✓ 才提交记录。

## 恢复与保护

- 关闭配图面板不等于取消云端任务，重新打开后在本记录任务中查询原结果，不重新生成。
- 正文或编辑页变化后不沿用旧光标；图片保留在本记录任务中。关闭面板、重新选中文字，再打开配图点击「插入当前选段下方」。
- 网络提交超时无法确认是否计费时标为「提交未确认」，不自动重发。请先核对百炼控制台；移除任务不会取消云端生成或退款。
- 同记录未完成或未确认任务未处理前不创建新任务；生成图片先保存本机草稿，再确认任务完成，重复回调不重复插入。
- 生图 Key 使用 AndroidKeyStore 加密，公开配置只返回“是否已配置”，不回显 Key。安装包不含用户真实 Key。
- 选中文字发给当前助手，提示词与主动选用的参考图发给百炼；位置数据不参与配图。任务不含 Key 或远程签名下载地址。
- 已插入图片随记录备份；任务、未提交草稿及生图配置不在记录备份中。

## 限制

生图需要联网、有效 Key、模型权限与额度。画风提示词和参考图帮助保持系列风格，不保证主体、构图或文字绝对一致；图中文字、架构箭头与事实关系必须核验。默认无文字以降低错拼风险，不把插画用作技术论证。当前使用北京地域接口，不自动切换其他地域；业务空间可选填。
