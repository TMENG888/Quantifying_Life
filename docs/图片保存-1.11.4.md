# 图片保存 · 1.11.4

## 使用

打开记录中的图片或「图片 → 生成图片 → 放大」进入预览：

- 长按图片，选择「保存图片到相册」。
- 或直接点底部「保存图片」，成功后按钮显示「已保存」。
- 预览中的放大、缩小、双指缩放与拖动保持不变；滑动或双指操作不会误触长按菜单。
- 返回键先关闭长按菜单，再关闭预览，不退出记录。

Android 10 及以上写入系统相册 Pictures/知时；相册应用通常展示为「知时」相册。Android 8/9 通过系统文件窗口选择保存位置。无需申请读取整个相册或旧版写存储权限。

## 边界

- 保存应用内已经存在的 JPEG 副本，不访问模型、不重新生成，也不重新压缩。AI 生图在首次进入 App 时原有的格式转换不在本次变更范围内，不能称为恢复供应商的原始输出文件。
- 记录、图片引用和草稿不被保存动作修改，生成库图片也不必先插入笔记才能保存。
- 单次保存防止连续点击重复导出；关闭预览后重开，可主动再保存一份，不覆盖已有文件。
- 只允许有效本机图片编号，不接受外部 URL、任意文件路径或缺失图片。
- 保存失败会显示错误并恢复按钮；Android 10+ 尚未完成的相册项会清理，App 内原图保留。
- 导出后的图片成为用户相册文件；后续删除 App 内记录不会同步删除相册副本。

## 验证

使用合成图片，在 Android 模拟器验证真实相册写入、导出字节一致性、长按菜单、保存按钮、重复点击、失败重试、阅读预览与生成图预览，以及原有图片缩放和草稿流程。不调用收费生图；用户小米真机及 Android 8/9 文件窗口需后续验收。
