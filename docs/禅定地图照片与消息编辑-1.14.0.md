# 知时 1.14.0：禅定、手势地图、沿途照片、消息修改

## 禅定

在「今日」点「禅定」，直接正向计时，不设目标和倒计时。支持暂停、继续、结束；结束后可选填感受，历史按日历查看，不增加底部导航。

Android 使用包含休眠时间的单调时钟，不受用户调整系统时间影响。同一次系统启动中，即使 App 被系统结束，重新打开仍能恢复计时。手机重启会暂停在最后一次已确认时长，不把关机时长凭空补算进去，可能损失最近一次确认之后的时间。无需持续定位、后台前台服务或唤醒锁，也不会因后台 LLM 请求占满线程而延迟计时操作。

已结束的禅定记录随普通记录备份恢复；重复编号跳过，不覆盖已有感受。未结束的计时不跨手机恢复。

## 地图双指缩放

两指张开放大、合拢缩小，围绕手指中点缩放，可同时平移；松开一指后可接着拖动。保留「＋／−／全程」按钮。拖动与缩放不会误选轨迹点，也不改变原始定位、轨迹算法或参考里程。无本地底图的区域仍是网格，手势不能生成缺失的街道细节。

## 沿途照片

1. 在「轨迹」地图下的「沿途照片」点「开启同步」。
2. 系统提示时授权相册与照片位置信息。Android 14+ 若仅授权部分照片，就只读取被允许的照片。
3. 在小米相机中开启保存位置信息；以后正常拍照即可。在 App 前台相册发生变化、回到 App 或再次打开轨迹页时会自动读取，无需逐张导入。并非保证 App 被关闭时仍持续后台扫描。
4. 选择拍照当天，在地图看照片缩略图；邻近照片合并显示数量，点击可展开与预览。时间段／时刻筛选也作用于照片，时刻显示前后一分钟内的照片。

数据优先使用系统拍摄时间，缺少时读取 EXIF 原始拍摄时间；二者均无时明确标注「相册加入时间」。仅用照片自身 GPS，不按附近轨迹猜地点。无 GPS 的照片仍显示在下方照片栏，标注「无地点」。截图、微信转存图片常无 GPS；相机定位误差也不会因此消失。

不向模型或第三方服务上传照片和拍摄元数据。只读原相册，缩略图／预览按需缩小解码；首次读取缺少系统拍摄时间的大相册可能较慢，本机缓存元数据以减少重复读取。一天最多展示 500 张并明确提示；原图仍由系统相册保管，删除或撤销授权后可能无法预览，停止同步不会删除原图。照片不是轨迹点，不加入定位反馈、GPX 或轨迹里程。仍可单独使用原有在线底图选项，其图块请求隐私提示保持不变。

## 已发送消息

单击自己发出的文字：带回底部输入框，显示「修改输入」，改完点发送。长按：弹出复制、选择文本、修改。选择文本可只复制其中一段。不提供分享入口。

点修改栏的「×」恢复原先未发送的草稿；不改旧消息、不自动发送、不修改已保存生活记录。改完发送会追加为一条新消息，AI 仍可参考前面对话；这不是删除后续消息、替换历史或对话分支。旧附件不自动重传，需要时重新添加；当前已选择的待发附件保持原样。键盘可用 Enter／空格进入修改，菜单键或 Shift+F10 打开操作菜单。拖动阅读历史不会触发长按菜单。

## 验证范围

自动化逻辑测试及 Android 15 / WebView 124 模拟器的真实触摸事件测试，使用合成照片、EXIF、位置和回复，不调用付费模型、不上传位置。小米实体机相册权限弹窗、不同相机的 EXIF 行为与后台策略仍需用户手机验证。没有为了让照片贴图而改写或补造原始轨迹。
