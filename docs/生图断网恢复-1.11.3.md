# 生图断网恢复 · 1.11.3

## 修复

- 提交、保存记录或查询失败时，面板显示具体原因并恢复按钮，不再残留「正在提交」。
- 明确收到 400/401/403/429 等拒绝响应，或写入请求前无法建立连接时，标为失败；恢复网络/修正配置后可手动重试。
- 发送后丢失响应、超时、5xx 或缺少任务编号时仍标为「提交未确认」，不自动重复发送付费请求。
- 无任务编号的未确认任务提供「核对后解除占用」，需明确确认可能重复扣费；解除仅清理本机占用，不会取消服务端生成或退款。
- 有任务编号的配图继续查询原任务；网络恢复、切回 App 和重开面板不会触发重新生图。
- 对请求增加 45 秒连接断开看门狗（连接 15 秒、读取 20 秒超时保留），限制上传/慢响应占用。活动请求不能手动解除，进程退出留下的提交中任务可立即进入未确认恢复流程。
- 已提交但任务列表刷新失败时保留已提交状态；图片和笔记不受影响。

## 使用

覆盖安装，不要卸载旧版。遇到「提交未确认」先在百炼控制台核对任务与扣费：有任务编号就查询原任务；无编号且已核对时才解除本机占用，再决定是否手动重新生成。

## 验证原则

使用 Android 模拟器、实际 WebView 和原生适配器，通过合成响应模拟断网、丢失回执、拒绝响应、进程中断和上传阻塞；不使用真实 Key、不提交收费生图。手机真实网络切换的最终体验仍需真机验收。
