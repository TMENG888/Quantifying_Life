# 知时 1.17.0：玄黄界面与领域仪表盘

## 界面

使用 Nutlope/hallmark 2.0.0 的重设计流程，结合现有 Android WebView 功能落地。主色由用户指定为玄黄：黄色主面与玄黑文字，阅读／编辑使用浅纸面。统一首页、记录、工作日历、随笔、轨迹控件、AI 助手、模型配置和弹窗的颜色令牌与触达尺寸。底图、轨迹语义线、用户图片不作滤色。

底部仍为今日、记录、轨迹、AI 助手四个入口；原有操作与数据不删除。首页先看当天投入与本月积累，点击学习／工作／随笔汇总进入对应仪表盘。

## 领域与标签

在已有细标签上增加“领域 → 主题 → 原始记录”层。领域条目显示篇数、已记录时长与主题数，可点击查看来源。下方保留主题细目及原标签下钻。

默认归类是本机可解释的标签规则，不调用付费模型，也不依据正文猜测领域。没有匹配规则的标签显示“其他主题”；没有标签的记录显示“未分类”。在“调整领域归类”可把一个标签归入已有或自定义领域，或恢复该标签默认。

领域映射只存本机 WebView 设置，不改原记录，不随现有 JSON 备份导出；卸载或清除应用数据后需重新设置。相同主题在学习、工作、随笔中可分别归类。

## 统计口径

- 同一记录包含多个同领域标签，在该领域内只计算一次。
- 同一记录跨领域时会在各领域出现，领域不能相加；顶部总量保持唯一计数。
- 学习时长只读取原记录分钟，不估算阅读时长。
- 工作净工时读取班次，按所选自然日截取并扣休息。日志只计篇数，不继承同一天的班次时长。
- 随笔合并经验与灵感，只统计篇数和记录日，不虚构学习或工作时长。
