# 一键导出全部定位反馈包

入口：「轨迹 → 轨迹数据 → 导出全部定位反馈包」。确认位置隐私提醒，选择保存目录，等到显示“已保存全部定位”后再分享 ZIP 文件。Android 安装包仍直接交付 APK，不压缩安装包。

## 包含什么

- 导出开始时所有已保存日期的所有原始定位点，不按误差、可信速度、传感器状态、来源、eligible 或模拟标志过滤，也没有单日 120000 点的限制。
- 每个点保留 id、毫秒时间、坐标、误差、会话、GPS/fused 等来源、模拟标志、原始速度及速度误差；已有 telemetry 字段完整保留，包括运动 RMS、新鲜度、注册/唤醒状态、卫星信号、GPS 失联时长等。旧版本没有采集的字段不会伪造补齐。
- 当前 App/算法版本、当前轨迹方案、采集策略和设备厂商/机型/Android版本；各日期的原始点数、起止时间和整包完整性标志。
- 原始坐标是 WGS84，时间为 Unix 毫秒；date 按导出时的手机时区分组，时区写在清单中，绝对时间不会改变。

不包含模型 API Key、学习/工作笔记、对话、Wiki 文档、离线地图或设备唯一标识。此包用于原始数据回放，不重复放入整套处理后坐标或 GPX；使用包内原始点及算法版本可重新处理、比较。

## 完整性与内存

这是一个 ZIP，内有 header.json、raw-points.jsonl 和最后写入的 manifest.json。原始点按自增 id 排序，一行一个 JSON。清单记录快照 id 上限、全量点数、每一天的点数与原始 JSONL 字节流 SHA256。只有完整导出并关闭文件后才提示保存成功；没有完成清单或 ZIP 不完整时不应作为有效反馈包。

每页读取 1000 点、逐行压缩写入用户选择的位置，不把全部历史加载到内存，不产生另一份临时全量明文文件。导出期间可继续采集：新增 id 超过快照上限的点留待下一次导出，保证单次统计一致。导出时暂不允许删除轨迹，避免生成缺点的包。原始数据库和其他记录不会被导出操作改写。

若取消保存，不生成反馈包；若存储满、权限失败、页面进程中断，可能留下不完整的文件，不会给出成功提示，需重新导出。历史很多时请保持 App 打开，保存完成后再发送。

## 隐私

这个包仍含住址、活动区域与完整行踪。压缩不是加密。只保存到用户选择的位置，不自动上传、不调用模型、不自动分享微信；若选择云盘文档提供方，是否同步由该提供方决定。用户自行决定是否把文件分享给可信的分析人员。已删除或从未采集到的点不能通过导出恢复。

在 Windows 本机校验包（只打印汇总，不输出坐标、不解压文件）：

```powershell
./tools/inspect-track-feedback.ps1 -Path '反馈包路径.zip'
```

当前界面保留单日 GPX、原始 GPX 和定位诊断，也保留当天删除操作；单日按钮调整为两列，整包反馈为顶部全宽主按钮。
