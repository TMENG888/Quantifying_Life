# 信息积累与滚动加载 · 1.20.0

知时新增保存记录的信息单元分析，统一随笔入口，并将记录列表改为滚动追加。

## 统计与图表

- 信息量 N：一篇正文中可以独立表达的知识、事实、方法、条件、观点或因果关系。篇内同义重复合并，跨篇重复仍计入；不按句子或行数计数。
- 信息密度：`ΣN / ΣC × 1000`。C 按正文 Unicode 码点统计，去除空白、Markdown 格式、普通链接地址与图片占位，保留标点及代码内容。
- 学习信息生产效率：`ΣN（有效时长的已分析学习记录）/ Σ分钟（同一组记录）× 60`。另显示对应的分钟／单元成本。不将整班工时分摊到工作日志，随笔不估算耗时。
- 日／周／月统计。周一为周始；边界周期按所选日期范围显示。缺失结果与无记录日期保留为空，不能当作零。
- 数量采用柱图，便于比较各时段的总量；密度、效率采用独立折线，便于观察变化，避免不同单位共轴。无数据的区间断开；没有重新加入散点图。
- 各时段可展开到记录、独立信息单元及原文依据，再打开原记录。默认只展开必要信息，大字体时指标纵向排列。

这些指标描述记录的信息积累，不能直接证明理解、信息正确性或认知进步。摘录、导入及 AI 辅助内容同样可能有信息单元，不自动等同于个人掌握。

## 自动分析

仅正式保存的 learning、work_note、idea、experience 正文进入后台队列。编辑草稿和自动保存草稿不触发分析；勾选保存成功后自动调度，历史已保存内容自动补处理。复用加密保存的阿里云生图密钥及业务空间，固定 qwen3.7-flash。

正文按段独立缓存；长段继续分块，全部内容读取完才形成完整结果，没有 6000 字截断或信息单元数量上限。新增／修改只重新提取变化段；全文跨段同义去重需重新核对。相同段内已经在提取时去重，不再二次合并独立要点。提取、去重均使用严格 JSON Schema，返回值仍经过来源编号、覆盖率、摘要长度与结构校验。

修改后替换该篇结果，删除的内容不再累计。每一步按原文版本及哈希提交，旧请求不能覆盖新正文或复活已删除记录。失败保留数据库进度，格式／长度问题会缩小片段，网络与限流按后台策略重试；用户可点击重试分析。系统限制后台或强制停止 App 时可能延后，重新打开继续。

来源位置采用 UTF-16 偏移，引用原文片段。分析导出包含版本化的完整信息单元、计算口径和来源，过滤任意附加嵌套字段。分析不改写正文、用户标签、日期或原始时长。

## 随笔与列表

随笔统一「写随笔」，去掉灵感／经验选择、筛选、徽章与分开计数。旧 idea／experience 类型保留兼容，阅读、修改及检索继续覆盖两者，新随笔内部使用 idea。

学习、工作日志、工时、随笔、当天时间线先渲染 20 条，接近底部再追加 20 条；保留「加载更多」备用入口。追加节点保留现有 DOM 和滚动位置。原文只在列表预览中缩短，搜索、筛选、统计与导出仍使用全部数据。阅读后返回保留已加载批次，改变筛选重置批次。

本次采用分批追加，不是数据库分页或滚动回收；记录仍完整加载到本机状态，连续滚动很长列表时，已加载节点也会增加。

## 验证范围

脚本回归、原生数据库／增量／错误恢复、Android 模拟器界面与真实 Qwen 调用分开验证。具体本次交付结果见 APK 同目录的验证说明。测试模拟器使用合成列表与用户已授权的历史导出，未将测试数据或密钥打入安装包；未声称已在用户实体手机验证。
