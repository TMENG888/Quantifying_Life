# 第三方地图组件与重新链接

应用源码与第三方库的许可证分别适用，不把第三方库的许可证改成应用许可证。

- Mapsforge core、map、map-reader、map-android、themes 0.25.0：LGPL-3.0-or-later；版权所有 Mapsforge 项目贡献者。完整 GPL 与 LGPL 文本随 APK 位于 assets/licenses/，源码 https://github.com/mapsforge/mapsforge/tree/0.25.0 。对应 Maven Central 的 sources.jar 与版本源码可获得，未修改上游库。
- AndroidSVG 1.4：Apache-2.0；版权所有 Paul LeBeau / AndroidSVG contributors。完整许可证随 APK 位于 assets/licenses/androidsvg-Apache-2.txt；源码 https://github.com/BigBadaboom/androidsvg/tree/1.4 。
- Mapsforge 测试地图仅用于测试，不作为城市底图交付：mapsforge-map-reader/src/test/resources/with_data/output.map，版本0.25.0，SHA256 63FCE6449BB400841B0BDC2B16137DD8B77C2CF7EED8C4C5D41393F752A30DAE。

构建脚本 tools/fetch-map-deps.ps1 锁定版本与 SHA256，从 Maven Central 下载未修改的 jar。Gradle 构建声明同版本依赖，Windows 手动构建用 classpath 编译，并由 d8 重新合并依赖，保留主题资源。

重新链接：获取本仓库相应应用源码及 Mapsforge 0.25.0 源码，按上游构建说明生成替换 jar。出于供应链安全，默认脚本会拒绝修改过的 jar；测试自己的修改时自行调整 fetch-map-deps.ps1 中相应校验值（不要关闭默认校验），或在 Gradle 中换成本地 project/files 依赖。运行 tools/build.ps1 生成自用 APK。无需原开发者密钥来运行重新链接版本；自有签名不能直接覆盖官方签名安装，应先自行备份，使用不同 applicationId 测试避免影响现有数据。允许为调试这些库的修改而进行必要的逆向工程，不以应用条款限制 LGPL 赋予的权利。

没有复制 GPL GPSLogger 源码；采集生命周期使用 Android 公共 API 独立实现。没有复制许可未明确的 mad-location-manager-lib 当前 C++ 实现，也没有宣称已移植其完整融合算法。运动辅助与位置平滑为本应用独立实现。未引入 Valhalla/GraphHopper 服务或其路网数据。
