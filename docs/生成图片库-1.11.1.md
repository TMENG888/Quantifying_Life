# 知时 1.11.1 · 配图与生成图片库

## 怎么用

1. 模型配置中分别保存助手 Key 和北京地域百炼生图 Key。参考图策划要求当前助手支持图片输入。
2. 在学习、工作日志、灵感或经验正文中选中文字，点「配图」。选区高亮、手柄和系统操作菜单会隐藏。
3. 先选参考图，再点「准备提示词」。可用本记录或已生成的图片。参考图参与助手视觉理解，也会随最终提示词交给千问生图。
4. 有参考图时优先沿用其背景、配色、线条、图标和图解布局语言，不再强制米白墨绿；无参考图时仍可选纸面墨绿等画风。App 本身保持绿色。
5. 检查提示词后点「生成图片」。直接调用，不另弹费用提示。修改参考图、画幅或文字设置后，旧提示词会失效，需重写或手动编辑确认。
6. 可以关闭面板或退出 App。结果不会自动写进正文。重开 App 后会用原任务 ID 继续查询，提交状态不明时不会自动重发。
7. 要插图时，打开任意记录放好光标，点「图片 → 生成图片」，可放大预览、多选，再点「插入」。已插图不会从图库消失，可在其他记录复用。插图支持撤销；记录需点「✓」提交。
8. 手机相册入口在「图片 → 本机图片 → 从手机选择」。原系统选图和草稿恢复机制保留。

## 持久化与边界

- 生图任务和下载的图片保存到 App 私有存储，提示词表单也有本机草稿。图库不依赖旧记录的 DOM 光标。
- 前台定时查询和重开恢复相互独立于配图面板。Android 结束进程后不保证持续下载，不承诺后台永远运行；重开可恢复原任务。
- 原任务 ID 不变，网络超时不自动重发付费生成请求。若连提交是否成功都无法确认，应先检查百炼控制台。
- 插入时验证当前记录、正文版本和光标有效性，不猜测过期位置；失败时图片仍在图库。
- 生成图的文字、布局及技术关系需人工核对。参考图能提高一致性，不保证完全复制风格；插画不是事实依据。
- 只有主动选中的文字和参考图送到模型服务；未选全文、位置轨迹及 Key 不作为资料输入。参考图会同时发送给助手厂商和百炼。
- 密钥使用原加密设置保存，不打包进源码或 APK。未插入记录的图库不是现有记录备份的一部分；已插入图片随记录备份。
