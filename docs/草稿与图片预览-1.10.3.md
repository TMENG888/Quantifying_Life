# 草稿与图片预览 · 1.10.3

## 草稿判定

- 新建学习笔记、工作日志、灵感、经验，未输入直接退出，不保存草稿。
- 打开信息抽屉不会改变默认字段；日期控件未编辑时保留原始秒数、未填写字段和历史数据。
- 标题、正文、图片、时长、平台、链接、标签等实际内容可以独立留作草稿；主动修改日期／时间也可恢复。
- 自动保存后清空新记录，会在已排队的保存完成后清除本条空草稿。不会清除其他记录的草稿。
- 修改既有记录时，即使删除了正文，修改仍可留作草稿，避免丢失有意编辑。
- 历史默认字段生成的空草稿只从列表隐藏，不批量删除数据库内容；有内容的未命名草稿保留。

## 草稿列表

暖白卡片沿用绿色主题，按最近编辑排序。类型和保存时间位于顶部，标题与两行正文摘要分层，底部显示继续编辑。摘要移除 Markdown 标记和本机图片标识，仅用于展示，不改原文。未命名笔记优先用正文首行作为卡片标题；不会将该展示标题写入原记录。

## 图片预览

编辑与阅读模式的本机记录图片均可点击预览。支持双指缩放、双击放大／复位、按钮缩放、放大后的滚动拖动与适应屏幕。返回先关闭图片，不退出记录，也不修改正文、图片引用或记录时间。不向模型或外部服务上传图片。

## 验证范围

- Node 自动化测试：263 项通过。
- Android 30 隔离模拟器、WebView 83：`DraftPreviewTest` 在 360 dp 和 411 dp 两种宽度各通过 29 项检查，包括原生屏幕点击打开图片、缩放处理、横向滚动、草稿恢复和异步保存后清空。
- 可视化编辑回归：28 项通过；文档编辑与安全检查见本机交付验证说明。
- 兼容旧版 WebView 的四边定位和卡片间距；APK 与前版同签名，可覆盖安装。
- 未在用户小米真机上代测。建议覆盖安装前导出记录备份，不要卸载旧版。
