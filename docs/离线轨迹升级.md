# 1.9.0 本机轨迹升级（历史版本）

当前 1.9.1 已替换运动辅助处理与默认策略，详见 [停留与移动识别](停留与移动识别-1.9.1.md)。以下为 1.9.0 的历史设计说明，不代表当前默认行为。

## 实际交付

1. 采集：LocationManager GPS 请求约2秒，不再入库前按4秒、跳移或100米误差裁剪回调。原始库保存合法坐标和0～1000米误差内回调；过旧、重复、来源信息作为遥测保存。不能采集系统未返回的位置。
2. 持续采集：保留前台通知、心跳、暂停/重启状态；GPS持续缺失时最多每2分钟重订阅，不反复创建新会话。没有全天无限持有唤醒锁，也不能承诺绕过小米省电限制。
3. 运动辅助：线性加速度RMS仅用于辅助识别静止；至少连续10秒的可信低速GPS和新鲜低加速度共同支持才锁点。运动时采用高增益的标量卡尔曼位置平滑，避免明显滞后；没有手机姿态变换、惯性推算或交通方式识别。传感器缺失/过旧时不把未知当静止，匀速车辆低加速度也不会独自触发锁点。系统不唤醒该传感器时会退化，不谎称具备完整Mad库融合。
4. 默认仍为D，只有一个运动辅助试用选项。两者在同一天可切换，显示对照点数、距离与缺口数；两者均不改写原始点。普通GPX使用当前处理方案，原始GPX未经筛选。
5. 完整日：处理安全上限120000原始点，支持2秒/全天43200点。多于20000处理点时仅对绘图按1米容差、15秒窗口做几何简化，时间断层和会话端点保留。参考距离、GPX均按完整处理点，不按稀疏画线重新估算。上限外明确标注，不静默截掉后半天。
6. 地图：接入Mapsforge 0.25.0，可导入512MB内.map文件，本机渲染z2～18；保留原栅格MBTiles兼容，坏地图导入不会覆盖旧图。地图包无覆盖时仍显示网格，不虚构街道。App不自动下载地图，原离线模式不建立网络连接。

Android12以上可用的系统fused仅作备援采集，无Google Play依赖，不主动订阅network定位；运动辅助只在GPS缺失15秒且fused误差≤35米时使用，保留真实provider，来源切换分段不计跨源里程。系统定位自身是否使用网络由手机系统设置决定；App不把整条轨迹发送任何外部服务或AI。

## 尚未实现，不能混同

没有接入离线Valhalla/GraphHopper路网匹配：Mapsforge.map及栅格MBTiles都是显示数据，不是这些引擎的可路由图。需另选地区路由图及Android本机引擎、评估空间和许可，再做步行/骑行/乘车分模式验证。当前没有任何贴路效果或推断路线冒充定位。所有按时间相邻轨迹段仍以紫色虚线补连，不计里程、不写入普通GPX。

## 对照方法

先导出备份，不卸载旧版，安装同签名APK覆盖。在同一手机同时记录知时与自行安装的GPSLogger/OpenTracks，固定线路：原地停留、步行直角与高楼旁、骑车、匀速乘车、室内后返回室外。比较开始结束时间、转角、缺口、静止漂移与参考距离；没有高精度地面真值时，不把贴路或两软件一致当绝对精度证明。新传感器辅助只对新版重新采集且有有效遥测的数据有意义。

## 验证范围

JVM回放覆盖静止漂移、步行、骑行、匀速乘车、拐角、缺失/过期传感器、原始不变、来源切换与43201点完整日。Android模拟器验证同签名1.8.0升级、实际LocationManager回调、SQLite完整日、普通/原始GPX、真实Mapsforge渲染与UI方案切换。具体结果以交付说明为准。

这些是软件回归与合成定位验证，不是实体小米手机的精度、电耗或全天后台可靠性测试。
