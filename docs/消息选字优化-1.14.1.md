# 知时 1.14.1：消息选字优化

- 长按用户消息直接弹出「复制、选择文本、修改」，没有 App 自制分享入口。
- 去掉触摸焦点和正在修改消息的彩色矩形边框；外接键盘 Tab 导航仍保留焦点提示。
- 选择文本改成底部圆角面板：居中标题、右上角关闭、可滚动的纯文字正文。没有文本框边框，不弹键盘，不自动全选。
- 长按面板正文使用 Android 原生选区手柄和复制菜单，移除重复的「复制所选文字」按钮。系统菜单的语言、颜色及附加选项由手机系统决定。
- 原文通过 textContent 显示，HTML 符号只作为文字；选字不会编辑、保存或发送消息，不调用模型 API。
- 沿用绿色／米白风格；单击带回输入框、取消恢复草稿、修改重发追加消息的逻辑保持不变。

覆盖安装即可；不清空原记录、聊天或模型配置。
